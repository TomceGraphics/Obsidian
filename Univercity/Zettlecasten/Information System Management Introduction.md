#### Information system
An information system can be defined as a set of interrelated components that **collect** (input), **manipulate** (process), and **disseminate**[^5] (output) data. An information system in its core is a sociotechnical[^4] entity.
##### The (IPOF) model
An Information System operates through four primary actions, often referred to as the **IPOF model** (Input, Processing, Output, and Feedback):
- **Input:** Collecting raw facts from the environment.
- **Processing:** Converting raw data into a meaningful form.
- **Output:** Disseminating processed information to users.
- **Feedback:** The "loop" where output is used to evaluate and correct the input or processing stages.

Because these functions operate in a continuous cycle, an Information System is essentially a **closed-loop system**. This ensures the system remains accurate and achieves its intended purpose over time.

There are 3 dimensions of an information system.
- Organization - the body/structure 
- Management - the brain
- Technology - the infrastructure

This is also know as the OMT model
