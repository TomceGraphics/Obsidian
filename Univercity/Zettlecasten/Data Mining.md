The process of discovering **patterns, correlations, and anomalies** in large datasets to generate useful business knowledge.

## Core idea
Data mining applies statistical and ML techniques to find things you didn't know to look for — going beyond reporting what happened to revealing *why* and *what's likely next*.

## Types covered in lecture

### Text mining
- Extracting patterns and meaning from unstructured text
- Examples: sentiment analysis, topic modeling, spam detection

### Web mining
- Analyzing web data to discover patterns in user behavior, content, and structure
- **Distinct from web scraping** (lecture Q&A):
  - Web scraping = collects *publicly visible* data
  - Web mining = analyzes *user behavior patterns* (clicks, navigation paths, session data) that scraping cannot access

## Common techniques
- Classification (predict a category)
- Clustering (group similar records)
- Association rules (e.g. "customers who buy X also buy Y")
- Regression (predict a numeric value)
