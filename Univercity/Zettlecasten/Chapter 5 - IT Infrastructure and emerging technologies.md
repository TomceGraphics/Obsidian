# Chapter 5 - IT Infrastructure and emerging technologies
From: *Management Information Systems*, Laudon & Laudon (17th ed.)
Course: ICS16M01 — Information Systems Management, Aleksandar Karadimce PhD

## What is IT infrastructure?
The set of physical devices and software required to operate an enterprise — viewed as a **service platform** that the whole organization depends on.

## Evolution of infrastructure
| Era | Period | Key shift |
|---|---|---|
| Mainframe | 1959–present | Centralized computing |
| Personal computer | 1981–present | Computing at the desk |
| Client/server | 1983–present | Networked distributed computing |
| Enterprise computing | 1992–present | Internet-connected systems |
| Cloud & mobile | 2000–present | Computing as a utility |
| AI-driven | 2020–present | Intelligent, adaptive systems |

## Technology drivers
- **Moore's Law** — computing power doubles roughly every 2 years while costs fall
- **Metcalfe's Law** — the value of a network grows exponentially with the number of users connected to it

## Infrastructure components
1. Computer hardware (laptops, servers, mainframes)
2. Operating systems (Windows, Linux, iOS)
3. Enterprise software (SAP, Oracle)
4. Data management (SQL, Hadoop)
5. Networking (Cisco, Verizon)
6. Internet platforms (Apache, .NET)
7. Consulting and system integration services

## Current trends

### Hardware trends
- Quantum computing
- Virtualization (multiple VMs on one physical server)
- Cloud computing — [[cloud computing]] (SaaS, PaaS, IaaS)
- Edge computing
- [[green computing]]

### Software trends
- Open source (Linux)
- Web services and SOA (XML-based)
- Software outsourcing
