# TCO — Total Cost of Ownership

A framework for calculating the **full cost** of an IT investment, not just the purchase price.

## Components
| Category | Examples |
|---|---|
| Acquisition | Hardware, software licenses |
| Installation | Setup, configuration, migration |
| Operations | Energy, maintenance, staff salaries |
| Downtime | Lost productivity when systems fail |
| Retirement | Disposal, data migration when replacing |

## Why it matters
Firms often underestimate IT costs by only looking at upfront spend. TCO reveals the true long-term cost, enabling better [[Competitive Forces Model for IT infrastructure Investment|investment decisions]].

## Cloud and TCO
Cloud computing shifts costs from **capital expenditure (CapEx)** to **operational expenditure (OpEx)**, which changes how TCO is calculated — upfront costs drop but recurring costs rise.
